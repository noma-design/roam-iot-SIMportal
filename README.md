# Roam IoT — Portal

Post-login Control Center UI from the Roam IoT Figma designs.

Separate from the Auth screen app. Run on its own host/port.

## Breakpoints & grid

| Viewport | Width | Columns | Gutter | Margin |
| --- | --- | --- | --- | --- |
| Desktop | ≥ 1200px | 12 | 24 | 80 |
| Tablet | ≤ 1199px | 8 | 16 | 32 |
| Mobile | ≤ 767px | 4 | 16 | 16 |

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3001](http://localhost:3001).
